# 使用指南

DSH-Guild 是一个面向 DSH 用户的类 Discord 社区插件：注册一个社区账号后，就可以在 DSH 面板里自建或加入社区，实时聊天、贴图传文件、`@` 提醒、管理成员，全程不需要跳出 DSH。

只要有 DSH，就能当社区客户端用 —— 成员不需要额外安装客户端。

## 核心概念速览

| 概念 | 一句话说明 |
| --- | --- |
| **社区** | 一个独立的组织单元，有成员、角色、频道；分公开 / 私有 |
| **频道** | 社区内的聊天容器，分文字 / 公告 / 话题三类 |
| **话题（讨论组）** | 频道内的独立讨论串，适合「一个问题一条线」 |
| **角色** | 一组权限位的集合，成员可持有多个，权限按并集计算 |
| **权限覆盖** | 在单个频道上对 `@everyone` / 角色 / 成员单独 allow / deny |
| **分享** | 把本机一条 DSH 会话打包发到社区，别人可一键克隆 |

完整的权限模型见[权限与角色](/reference/permissions)。
