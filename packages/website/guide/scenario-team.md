# 场景二：团队 / 小组内部协作

[← 返回使用指南](/guide/) ｜ 相关文档：[插件作者管理社区](/guide/scenario-plugin-author) ｜ [会话分享广场](/guide/scenario-share-square)

团队用 DSH 干活，但沟通散在微信 / 飞书里，讨论结论和 DSH 里的会话上下文对不上。这个场景把沟通搬进 DSH 面板：每个人在自己本机的 DSH 里收发消息，讨论产生的会话可以直接打包分享给同事复现。

成员不需要额外装客户端 —— 有 DSH 就能用。

## 一、目标与最终形态

| 频道 | 类型 | 用途 |
| --- | --- | --- |
| `公告` | 公告 | 版本 / 流程变更，只读 |
| `日常` | 文字 | 全员闲聊与同步 |
| `技术讨论` | 话题 | 一个议题一条话题，结论沉淀在串里 |
| `值班与告警` | 文字 | 需要 `@everyone` 的紧急事项 |

角色：`@everyone`（成员）+ `负责人`（少数人）+ `实习生`（受限，可选）。

## 二、建一个私密社区

1. 面板 **＋** → 创建社区，可见性选 **私有**。
   - 私有社区不出现在发现页，只能凭邀请码加入，邀请码创建时生成且**固定不变**。
2. 把邀请码发给成员，他们在 **＋ → 加入** 里输入即可。
3. 也支持 **主动邀请已注册用户**：按用户名或邮箱邀请 → 对方收到**站内信 + 邮件**，在收件箱里接受 / 拒绝，铃铛有未读角标。

> 如果公司要求数据不出内网，可以让管理员把 Server 整体自部署到自己的 Cloudflare 账号，把插件设置里的 `serverUrl` 指过去。见 [自部署 Server](/dev/deploy)。

## 三、频道怎么配

- **公告**（公告类型）：默认对 `@everyone` 只读，全员进社区即订阅；只有所有者或经频道权限放行「发送消息」的角色能发。流程变更、值班表都发这里。
- **日常**（文字）：新建即全员可发言，不需要额外配置。
- **技术讨论**（话题）：频道主面板就是话题列表，每个议题开一条，独立成串；24 小时无人回复自动归档（有人回复即恢复），话题不会被日常闲聊刷没。
- **值班与告警**（文字）：紧急事项在这里发并 `@everyone`，会计入所有人的提及未读，不会被静默。

频道可在菜单里改名 / 改主题 / 删除，并用上移 / 下移排序，把高频频道排前面。

## 四、角色与权限

社区自带 `@everyone`（隐式作用于全体成员）与一个预设「管理员」角色（普通角色，按全部权限位初始化，需手动分配）。成员可同时持有多个角色，基础权限按**并集**计算。

### 建立分层

**负责人**（新建角色，勾选）：

- `查看频道` `发送消息` `发起讨论组` `管理讨论组`
- `管理消息`（能置顶、编辑 / 删除他人消息）
- `管理频道`、`邀请成员`、`移除成员`、`封禁成员`
- 一般**不给** `管理社区` 与 `管理角色`

**实习生 / 只读成员**（可选，新建角色）：

- 只勾 `查看频道` `发送消息`；
- 需要限制某些频道时，在频道权限里单独 deny（比如把 `公告` 的 `发送消息` 对 `@everyone` 保持只读，只给 `负责人` allow）。

### 两条硬规则

- **层级防提权**：只能操作层级严格低于自己的角色与成员 —— 负责人动不了所有者。
- **不能授予自己没有的权限位**：配置角色时，你没有的权限勾不上。

权限变更会**实时下发**：在线连接被重新校验，失去频道可见性的连接会被主动断开。

## 五、日常协作动作

- **发起讨论**：在 `技术讨论` 里新建讨论组；需要封闭讨论时把可见性设为 `私密`，可附加**进入密码**，或者不设密码、由组内成员从社区成员里主动拉人。
- **贴上下文**：截图、日志、配置文件直接**粘贴或拖拽**进输入框（一条消息最多 4 个附件）。
- **点对点打扰**：`@某人` 会高亮并计入对方的提及未读；全员级打扰用 `@everyone`，慎用。
- **确认在线状态**：频道头部显示当前在线人数，点开可看在线成员；窗口焦点切换会自动在「在线 / 离开」间切换。侧栏与成员面板还有跨频道的社区在线聚合。
- **找历史结论**：用消息搜索，按关键词模糊匹配，并用频道 / 作者 / 时间范围（24h / 7d / 30d）/ 仅 `@我` 收窄。
- **沉淀结论**：把结论用置顶固定在频道头部（需要「管理消息」权限），置顶面板可跳转到原消息。
- **表达态度**：用表情回应代替"收到"，同人同 emoji 再点即取消，聚合并实时同步。
- **交接**：人员变动时在成员面板移除成员；需要彻底阻止其重新加入就**封禁**，随时可解封。

## 六、把会话直接交给同事

团队协作里最省事的一招：**分享 DSH 会话**。

1. 在 DSH 里选中要交接的会话 → 分享到社区；插件会把本机会话打包上传（包体上限默认 50 MB，可在插件设置 `share.maxSizeMb` 调整）。
2. 同事在消息里点开分享卡片，弹窗里能看到分享者 / 大小 / 时间 / 事件数，一键 **克隆到本地的会话**。
3. 也可以只发一张**分享卡片**：发消息时附带一个自己创建的分享，卡片内嵌在消息里，点开即详情。

适合的场景：把复现出问题的会话丢给同事排查、把跑通的会话作为模板发给新人、把一次完整调试过程留档。

## 七、常见坑

| 现象 | 原因 / 处理 |
| --- | --- |
| 成员收不到邀请 | 邀请是「站内信 + 邮件」双通道；若 Server 未配置 `RESEND_API_KEY`，邮件不会发，让对方看面板里的收件箱 |
| 新人看不到某个频道 | 检查角色是否勾了 `查看频道`，以及频道权限覆盖里有没有对该角色 deny |
| 话题串消失 | 24h 无人回复自动归档，回复即恢复 |
| 讨论组进不去 | 私密讨论组需要密码，或需要组内成员拉人 |
| 自建社区报错 | 自建上限 20 个，且每 24 小时最多创建 5 个 |
